# Horizon

Launcher pour BlablaFantasy.

## Installer

Télécharger `Horizon-Setup-<version>.exe` dans la dernière [release](https://github.com/Voltingg/horizon/releases/latest), puis le lancer. L'installation se fait pour l'utilisateur, sans droits administrateur.

Horizon se met ensuite à jour tout seul : à chaque lancement, il vérifie la dernière version publiée ici et l'installe.
